# ParivaarCall brand

The approved identity is the **Embrace icon with the soft-serif wordmark (option B)**.
Use the spelling **ParivaarCall**.

| Asset | Location |
| --- | --- |
| Master logo | `final-logo/ParivaarCall-Embrace-Soft-Serif.png` |
| Master icon | `final-logo/ParivaarCall-Embrace-Icon.png` |
| App logo | `../../public/brand/parivaarcall-logo.png` |
| App icon | `../../public/brand/parivaarcall-icon.png` |

Run `npm run brand:sync` after updating the masters. App screens use
`components/ui/BrandLogo.tsx`.

- Use deep sage `#3D5644` on cream `#FFFAF3` or white.
- Preserve the supplied proportions, lettering, and clear space.
- Use the icon alone where the full wordmark would be too small.
- These are transparent raster PNGs, not vector or font sources.

Previous concepts, posters, editable reels, and exported videos were moved to
`../../../ParivaarCall-archive-2026-10-28/marketing/` beside the project.
Older video exports may contain superseded branding; re-render before reuse.
